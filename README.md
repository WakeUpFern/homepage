# homepage

Portafolio personal de **wakeupfern**. Vite + JavaScript vanilla + GSAP + Lenis, SPA con router propio.

```bash
npm install
npm run placeholders   # genera imágenes de ejemplo en public/assets
npm run dev            # http://localhost:5173
npm run build && npm run preview
```

Documentación de trabajo: [`BRIEF.md`](BRIEF.md) (especificación) y [`CLAUDE.md`](CLAUDE.md) (convenciones y decisiones de arquitectura).

Despliegue: Vercel (`vercel.json` reenvía todas las rutas a `index.html`).
